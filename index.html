Impact at Worldline International (M)

Three automations I led, and the time they saved.

30→5min to review one eKYC application Python · OCR · Vision AI Read the story
Problem
Every eKYC application was checked by hand, about 30 minutes each, which capped the team at 10 a day.
What I did
Built a Python tool that reads the documents with OCR and a vision AI model, so the checks run automatically.
Result
Down to 5 minutes per application, 60 applications a day instead of 10, and accuracy up from 90% to 94%.
120→60min to turn an audit trail into a report Python · OCR · Excel Read the story
Problem
Audit and finance teams needed audit trail PDFs of up to 10,000 pages as structured Excel reports. Each one took about two hours.
What I did
Built a Python and OCR tool that reads the PDFs and writes the data into a standard Excel layout.
Result
Report turnaround time (TAT) cut in half, from 120 to 60 minutes per report.
150+a day email requests logged with zero typing Power Automate · Excel Read the story
Problem
Three teams typed every email request into Excel logs by hand, more than 150 a day.
What I did
Built a Power Automate flow that captures each request from email straight into the log.
Result
No more manual entry, faster logging, and fewer errors.

I led each project from requirements to go-live, securing sign-off from the APAC AI team, solution architects, the Data Protection Officer, Legal, and senior management. To keep company data confidential, these stories are simplified.
